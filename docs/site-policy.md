# Site Policy

This site is maintained as an open technical writing and project documentation hub.

## No Ads

This site does not use display ads, Google AdSense, sponsored ad slots, or ad networks.

The goal of this site is not advertising revenue. The goal is to share open-source projects, engineering notes, and technical documentation in a clean and readable form.

## No Ad Tracking

This site does not use:

- ad tracking
- retargeting pixels
- behavioral advertising scripts
- third-party marketing tags for advertising

## Minimal Analytics

Analytics, if enabled, must be used only for aggregate site improvement.

Allowed purposes:

- understanding which technical documents are useful
- checking whether project pages are discoverable
- improving internal links and documentation structure

Not allowed:

- advertising optimization
- retargeting
- user profiling
- selling or sharing visitor data

## Search Visibility

Search tools such as Google Search Console may be used to monitor indexing, search queries, and crawl issues.

See also:

- [Analytics Options](analytics-options.md)
