# Analytics Options

Analytics is disabled by default.

This site does not use ads, retargeting, or behavioral advertising scripts.

## Option 1. No analytics

Recommended default.

Use only:

- server logs, if available
- GitHub traffic
- Google Search Console

## Option 2. Plausible

Preferred option if lightweight, privacy-friendly analytics is needed.

Use for:

- page views
- referrers
- top pages
- project page visits

Do not use for:

- user profiling
- advertising
- retargeting

## Option 3. Google Analytics 4

Use only if Search Console integration and broader ecosystem support are required.

Allowed:

- page views
- referrers
- project page visits
- GitHub outbound link click events, if needed

Not allowed:

- Google Ads integration
- remarketing
- advertising personalization
- cross-site marketing tags
